## 先定版本，再定机器：26.2 和 1.21 走的是两条路

2026 年起 Minecraft 版本改用日历编号，26.1、26.2 是最新的一串，旧系列的最后一个版本叫 1.21.11。现在大多数服务器仍跑 1.21，所以两个选择都成立：想要最新内容选 26.2，想和现存的大多数服务器、插件生态对齐就选 1.21。

版本一定，Java 版本就跟着定了。这里必须提醒一句，网上很多教程还停在“装 Java 17 就行”的年代，那只适用于 1.19 前后。

| Minecraft 版本 | 需要的 Java 版本 |
| --- | --- |
| 26.x（26.1、26.2） | Java 25 |
| 1.21.x | Java 21 |
| 1.20.5 及以上 | Java 21 |
| 1.18 – 1.20.4 | Java 17 |
| 1.17 – 1.19 | Java 17 |
| 1.8 – 1.16 | Java 11 |
| 1.7 及以下 | Java 8 |

1.20 这一档在不同资料里说法不一致：一份按 1.18–1.20.4 划到 Java 17，另一份把 1.20 及以上整体划到 JDK 21。稳妥的处理是按 1.20.4 和 1.20.5 做分界，1.20.4 及以前用 17，1.20.5 起用 21。真要拿不准，直接启动一次 Paper，控制台会打印它期望的 Java 版本，这是最省事的兜底办法。

Paper 已经不再为 1.0 到 1.15 发布任何版本，选太老的版本等于既没有更新也没有新插件可用。

## 服务端软件怎么选：Paper 是默认答案

原版（vanilla）是 Mojang 官方提供的服务端，完全不接受插件，只支持数据包，规则能力很有限。想装插件就得换核心。

| 服务端 | 能装插件 | 特点 |
| --- | --- | --- |
| 原版 vanilla | 否，只支持数据包 | 官方出品，规则能力有限 |
| Paper | 是，兼容 Bukkit 和 Spigot 插件 | 使用最广，明显快于原版，默认选择 |
| Purpur | 是 | Paper 的变体，可调项更多 |
| Folia | 部分 | 把世界分摊到多个 CPU 核心，部分插件不兼容 |
| Fabric / NeoForge | 模组路线 | 每个玩家都要在自己电脑上装对应模组 |

这里有个容易混淆的地方：Fabric 和 NeoForge 走的是模组路线，装的是 mod，不是插件，每个进服的朋友都得在自己电脑上装一套，版本还要和服务端对上。插件服对玩家零要求，朋友点 Join 就能进。如果你的目标是“朋友什么都不用装”，那就是 Paper 加插件。

Paper 的核心配置文件有四份：server.properties、spigot.yml、paper-global.yml、bukkit.yml。启动后用 timings 命令看性能报告，调整要循序渐进，优先动视距和实体数量，别一上来就改一堆参数。

## 4 核 8G 到底够几个人玩

Java 版服务端，尤其是 1.18 之后的高版本，吃的是 CPU 单核性能而不是核心数量。选机器时看 CPU-Z 单核跑分，600 以上是比较实用的筛选线，14900K、13900K、7950X、9950X 这类高主频 CPU 都是经过验证的选择。

内存按人数估：

| 同时在线人数 | 内存 | 说明 |
| --- | --- | --- |
| 2–4 人，偶尔玩 | 2–4GB | 原版或轻插件生存服足够 |
| 5–10 人 | 4–8GB | 加少量插件仍有余量 |
| 10–15 人 | 8GB | 4 核 8G 是这一档的常见配置 |
| 15 人以上或重度插件服 | 8GB 起，按需往上加 | 插件、红石装置、大量实体都会吃内存 |

“4 核 8G 支持 10–15 人”这个口径在教程里流传很广，它是带前提的：原版或轻量插件、视距没调到极端、没有几百个实体同时加载。反过来说，几个朋友玩生存、加少量插件，2–4GB 也是合理量级，不必一上来堆顶配。

顺便说一个参照：一家 2019 年开服、玩法接近原版的海外 Paper 生存服，7 天平均在线 6 人，日峰值 11，历史峰值 25。小服的常态就是个位数在线，这是判断配置时值得记住的量级。

## 雨云这台机器怎么买：NAT、线路、计费模式

**NAT 还是独立公网 IP。** 江苏镇江是 NAT 网络，多个用户共用一个公网 IP，也可以加钱选独立公网 IP。NAT 机型提供 15 个端口，端口范围 10000–60000，需要你自己在控制台做端口映射。Minecraft 只用 25565 一个端口，15 个够用，但你要记住一件事：映射出来的外网端口通常不是 25565，朋友连接时必须手动在 IP 后面加这个非标准端口。

**线路差异。** 浙江宁波有便宜的独立公网 IP，但是电信单线，高峰期其他运营商的用户延迟会明显偏高；镇江和宿迁都是 BGP 线路，各运营商用户延迟都较低，表现更稳。给一群人开服，优先 BGP。

**动态计费还是固定计费。** 雨云游戏云分动态计费和固定计费两种。动态计费在 CPU 占用率超过 20% 时会额外计费，每天有免费额度。这里有个反直觉的点：Minecraft 服务端恰恰是长时间高 CPU 占用的负载，只要有人在玩，占用基本压不住 20% 以下。动态计费适合“一周开一两次、玩完就关”的用法，长期 7×24 开着的服选固定计费更可控。

**年付 7 折。** 选购买时长时年付有 7 折，长期开的服值得考虑。配置选 4 核 8G 以上，后期人多了可以升级内存。

## 朋友连不上的四个真实原因

**一、端口没放行。** 服务器本机的防火墙、云厂商的安全组都要放行 25565（或你自定义的端口）。连不上先查这一项。

**二、NAT 机型没做端口映射。** 这是买回来连不上的头号原因。NAT 机型在控制台有「NAT 端口映射」入口，新建规则时协议选 TCP+UDP，内网端口填 25565，外网端口用系统分配的或自己填一个 10000–60000 之间的。填完拿到的外网端口，才是朋友要连的那个数字。

**三、面板端口和游戏端口都要映射。** 如果你用 MCSManager 这类面板管理服务器，它自己要占两个端口：23333（Web 面板）和 24444（Daemon 节点）。NAT 机型上这两个端口和 Minecraft 的 25565 都得映射，少一个就连不上面板。

**四、Docker 部署还要单独开放容器端口。** 用 Docker 跑服务端时，容器内的 25565 和宿主机的 25565 是两回事，得在应用实例控制里做一次端口映射，主机端口和容器端口都填 25565，协议选 TCP。

连接格式是「地址:端口」，冒号用英文的。本机测试用 localhost，朋友用的必须是公网地址。

## 别为了省事关掉 online-mode

server.properties 里的 online-mode 改成 false，没买正版的朋友就能进来，这是教程里很常见的做法。代价是：任何人都可以用别人的名字连进来，冒名顶替没有任何门槛，被 ban 了换个 ID 还能重新进。

如果你确实需要关掉，至少清楚自己在承担什么。另一个选择是保留正版验证，让没正版的朋友用 Geyser 从基岩版进，基岩玩家可以用自己原有账号，不必再买一份 Java 版。Geyser 是个插件，丢进 plugins 文件夹，配好之后它在自己的配置文件里监听另一个端口，路由器或端口映射那边除了 25565 通常还要再开这个端口。它不改变服务器性质，服务器仍然是 Java 服，插件照常对基岩玩家生效，只是部分菜单和特效在基岩端显示会有差异。
